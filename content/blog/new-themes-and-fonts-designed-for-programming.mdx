We published a new guide: [14 Best Fonts for Programming in 2026](/blog/best-fonts-for-programming-2026). It is a collection of modern variable monospace families, with download links and a few notes on what makes each one worth a try.

[![14 Best Fonts for Programming in 2026](/images/blog/new-themes-and-fonts-designed-for-programming-a.webp)](/blog/best-fonts-for-programming-2026)

You will find **Datatype**, **Geist Mono**, **Lilex**, **Martian Mono**, and ten more.

Pick one, live with it for a few days, and see if it sticks. If your daily driver is not on the list, [let us know on Discord](/discord-invite). We would love to hear what you are using these days.

## New on Dracula

We have 5 new additions to the clan:

- [LDoc](/ldoc): **LuaDoc-compatible documentation generator.** A documentation tool for Lua and C extensions.
- [mRemoteNG](/mremoteng): **Multi-protocol remote connections manager.** A Windows app for RDP, SSH, and VNC connections.
- [Neiki's Editor](/neiki-editor): **Lightweight rich text editor.** A dependency-free editor with built-in themes.
- [PeerTube](/peertube): **Decentralized video platform.** A free, ActivityPub-powered video platform.
- [Telegram macOS](/telegram-macos): **Official Telegram client.** The Telegram app for macOS.
