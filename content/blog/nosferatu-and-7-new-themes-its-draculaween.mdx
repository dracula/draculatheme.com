Happy **Draculaween!** The castle doors are open again, with a new Pro variant, a rebuilt JetBrains plugin, and seven themes from the community.

## Nosferatu, a new Pro variant

Meet **Nosferatu**, the _eighth_ Dracula Pro variant. Bone white on coffin black, lit by lantern flame, moss, moonlight, and dried blood.

[![A dark code editor showing a JavaScript class named Vampire with properties like location and birthDate, next to a file tree](/images/blog/nosferatu-and-7-new-themes-its-draculaween-a.webp)](/pro)

Already have Pro? The update is free in your [Gumroad library](https://app.gumroad.com/library).

## JetBrains themes rebuilt from scratch

The JetBrains theme is no longer at rest; this moon, it takes flight along with the rest of the clan. We rebuilt the plugin as a modern IntelliJ Platform package, so IntelliJ, WebStorm, PyCharm, and the rest finally match the Pro look you know from VS Code and Cursor.

What changed:

- A full rewrite.
- Syntax colors aligned with the VS Code and Cursor Pro themes.
- Every Pro palette, each with an Islands counterpart, including Nosferatu.
- Switching a Dracula Pro UI theme also switches the matching editor color scheme.
- Requires JetBrains IDE 2025.3 or later.

[![An IDE showing Java code about vampires next to a project file tree in the sidebar](/images/blog/nosferatu-and-7-new-themes-its-draculaween-b.webp)](/pro/changelog)

Details live in the [Pro changelog](/pro/changelog). Reinstall from the zip in your Gumroad library: **Settings → Plugins → Install Plugin from Disk…**, then pick a Dracula Pro palette under **Appearance**.

## New on Dracula

Seven new additions join the clan this Halloween:

- [Jenkins](/jenkins): CI/CD for the night shift, with **dark and Alucard themes** for the Jenkins server.
- [Rune](/rune): **codebase intelligence** meets a modern terminal experience.
- [Veilamp](/veilamp): a Winamp-inspired **music player** with peer-to-peer streaming.
- [Spotifast](/spotifast): a lightweight **Spotify client** written in Rust.
- [Polytoken](/polytoken): an **agentic coding harness**.
- [OpusWriter](/opuswriter): **novel writing** end to end, from outlining to drafting and publishing.
- [DeepSeek Harness](/deepseek-harness): a **DeepSeek agent UI** with sidebar, chat, and composer.
