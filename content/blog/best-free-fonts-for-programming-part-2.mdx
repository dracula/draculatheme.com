Five years ago we put together [14 Best Free Fonts for Programming](/blog/best-free-fonts-for-programming). Since then, variable fonts became the norm. Here is part 2.

## 1. Google Sans Code

Google built this one for its own products — Gemini, Android Studio, and beyond. The letterforms stay crisp at small sizes, with open counters and clear distinction between characters that usually get confused. It is one of the few coding fonts with a dedicated monospace axis on top of weight, so you can fine-tune how "code-like" it feels.

[Download](https://fonts.google.com/download?family=Google+Sans+Code) • [Github](https://github.com/googlefonts/googlesans-code)

[![Google Sans Code](/images/blog/best-free-fonts-for-programming-part-2-b.webp)](https://fonts.google.com/specimen/Google+Sans+Code)

## 2. Datatype

The newest font here, and one of the most interesting. Datatype lets you adjust both weight and width — rare for a monospace. Frank Tisellano designed it with data-heavy interfaces in mind, but it works just as well in a terminal if you want something that does not look like every other coding font.

[Download](https://fonts.google.com/download?family=Datatype) • [Github](https://github.com/franktisellano/datatype)

[![Datatype](/images/blog/best-free-fonts-for-programming-part-2-c.webp)](https://fonts.google.com/specimen/Datatype)

## 3. Lilex

If you like IBM Plex Mono but wish it had ligatures, this is the one. Lilex builds on Plex's clarity and adds programming ligatures, Powerline symbols, and Greek support. It landed on Google Fonts recently, and the weight range covers everything from light comments to heavy keywords.

[Download](https://fonts.google.com/download?family=Lilex) • [Github](https://github.com/mishamyrt/Lilex)

[![Lilex](/images/blog/best-free-fonts-for-programming-part-2-d.webp)](https://fonts.google.com/specimen/Lilex)

## 4. Intel One Mono

Intel open-sourced this family with accessibility as the main goal — reducing eye strain and helping developers with low vision read code for longer stretches. Frere-Jones Type drew the letterforms, and the result is clean and understated. It will not steal the show, but your eyes will thank you after an eight-hour session.

[Download](https://fonts.google.com/download?family=Intel+One+Mono) • [Github](https://github.com/intel/intel-one-mono)

[![Intel One Mono](/images/blog/best-free-fonts-for-programming-part-2-e.webp)](https://fonts.google.com/specimen/Intel+One+Mono)

## 5. Geist Mono

Vercel's type system made the jump from product UI to code editor. Geist Mono is neutral, well-proportioned, and pairs naturally with Geist Sans if you want the same typeface in your app and your terminal.

[Download](https://fonts.google.com/download?family=Geist+Mono) • [Github](https://github.com/vercel/geist-font)

[![Geist Mono](/images/blog/best-free-fonts-for-programming-part-2-f.webp)](https://fonts.google.com/specimen/Geist+Mono)

## 6. Ubuntu Sans Mono

Ubuntu Mono has been a Linux staple for years. This is its successor — same humanist spirit, updated to match the newer Ubuntu Sans branding. Dalton Maag kept the reliable feel that terminal users already know.

[Download](https://fonts.google.com/download?family=Ubuntu+Sans+Mono) • [Github](https://github.com/canonical/Ubuntu-Sans-Mono-fonts)

[![Ubuntu Sans Mono](/images/blog/best-free-fonts-for-programming-part-2-g.webp)](https://fonts.google.com/specimen/Ubuntu+Sans+Mono)

## 7. Reddit Mono

Reddit's open-source type system includes a monospace variant, and it is better than you might expect from a corporate font. Slightly rounded, friendly without being silly, and comfortable at 13px.

[Download](https://fonts.google.com/download?family=Reddit+Mono) • [Github](https://github.com/reddit/redditsans)

[![Reddit Mono](/images/blog/best-free-fonts-for-programming-part-2-h.webp)](https://fonts.google.com/specimen/Reddit+Mono)

## 8. Kode Mono

This one leans into nostalgia — Isa Ozler drew inspiration from early computer displays and pixel-era typography. The surprise is how well it renders at modern sizes. A fun choice if you want your editor to feel a bit retro without sacrificing readability.

[Download](https://fonts.google.com/download?family=Kode+Mono) • [Github](https://github.com/isaozler/kode-mono)

[![Kode Mono](/images/blog/best-free-fonts-for-programming-part-2-i.webp)](https://fonts.google.com/specimen/Kode+Mono)

## 9. Roboto Mono

Roboto Mono has been the default monospace on countless Android devices for years. The variable update makes it more flexible than ever. Neutral, familiar, and hard to argue with — sometimes boring is exactly what you need.

[Download](https://fonts.google.com/download?family=Roboto+Mono) • [Github](https://github.com/googlefonts/RobotoMono)

[![Roboto Mono](/images/blog/best-free-fonts-for-programming-part-2-j.webp)](https://fonts.google.com/specimen/Roboto+Mono)

## 10. Martian Mono

Evil Martians' first open-source typeface — a monospaced companion to Martian Grotesk with a tall x-height and a brutalist edge. The standout feature is the dual axis: squeeze or stretch the width and dial the weight. Great if you like tweaking typography as much as you like tweaking config files.

[Download](https://fonts.google.com/download?family=Martian+Mono) • [Github](https://github.com/evilmartians/mono)

[![Martian Mono](/images/blog/best-free-fonts-for-programming-part-2-k.webp)](https://fonts.google.com/specimen/Martian+Mono)

## 11. Chivo Mono

The monospace extension of the popular Chivo family. It inherits the sturdy grotesque skeleton of its sans-serif sibling and adds uniform widths for code. Popular for a reason — it just works everywhere.

[Download](https://fonts.google.com/download?family=Chivo+Mono) • [Github](https://github.com/Omnibus-Type/Chivo)

[![Chivo Mono](/images/blog/best-free-fonts-for-programming-part-2-l.webp)](https://fonts.google.com/specimen/Chivo+Mono)

## 12. Spline Sans Mono

The monospace counterpart to Spline Sans — rounded terminals, open apertures, and a warmer tone than most coding fonts. Softer personality, same clarity.

[Download](https://fonts.google.com/download?family=Spline+Sans+Mono) • [Github](https://github.com/SorkinType/SplineSansMono)

[![Spline Sans Mono](/images/blog/best-free-fonts-for-programming-part-2-m.webp)](https://fonts.google.com/specimen/Spline+Sans+Mono)

## 13. Azeret Mono

Designed by Displaay, Azeret Mono packs a wide weight range into a compact frame. Characters like `0` and `O` are easy to tell apart, and the narrow default width means more columns on screen.

[Download](https://fonts.google.com/download?family=Azeret+Mono) • [Github](https://github.com/displaay/Azeret)

[![Azeret Mono](/images/blog/best-free-fonts-for-programming-part-2-n.webp)](https://fonts.google.com/specimen/Azeret+Mono)

## 14. Red Hat Mono

The monospace member of Red Hat's corporate type system. Geometric, confident, and carefully spaced — it shares DNA with Red Hat Text and Display. Dependable in both light and dark themes.

[Download](https://fonts.google.com/download?family=Red+Hat+Mono) • [Github](https://github.com/RedHatOfficial/RedHatFont)

[![Red Hat Mono](/images/blog/best-free-fonts-for-programming-part-2-o.webp)](https://fonts.google.com/specimen/Red+Hat+Mono)
