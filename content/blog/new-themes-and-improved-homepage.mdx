The homepage just got a little better.

We added a new **Variants** filter so you can quickly find themes that support **Dracula** (dark) or **Alucard** (light).

![Variants filter on the homepage](/images/blog/new-themes-and-improved-homepage-a.webp)

When a theme has more than one preview image, you can now browse them in an interactive gallery with thumbnails — right on the theme page. No extra clicks, no leaving the site.

[![Interactive gallery on the Superset theme page](/images/blog/new-themes-and-improved-homepage-b.webp)](/superset)

## New on Dracula

We have 7 new additions to the clan:

- [DeepSeek](/deepseek): **AI-powered chat assistant.** A dark theme for the DeepSeek conversational AI platform.
- [FocusWriter](/focuswriter): **Distraction-free writing environment.** A dark theme for the minimal text editor FocusWriter.
- [Forgejo](/forgejo): **Self-hosted Git forge.** A dark and light theme for the Forgejo platform with auto theme support.
- [Hermes Agent](/hermes-agent): **AI agent by Nous Research.** A dark theme for the Hermes Agent platform.
- [Kagi](/kagi): **Privacy-focused search engine.** A dark and light theme for the Kagi search experience.
- [Swaync](/swaync): **Notification center for Sway.** A dark theme for SwayNotificationCenter on Wayland.
- [WhatsApp Web](/whatsapp-web): **Messaging in your browser.** A dark and light theme for WhatsApp Web with Dracula and Alucard variants.

[![Dracula theme for Hermes Agent](/images/blog/new-themes-and-improved-homepage-c.webp)](/hermes-agent)
