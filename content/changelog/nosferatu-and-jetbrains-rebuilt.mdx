### JetBrains rebuilt from scratch

The JetBrains theme is no longer a patchwork of legacy schemes. The plugin was rewritten as a modern IntelliJ Platform package with generated Pro palettes, Islands variants, and editor schemes that stay in sync with the UI theme you pick.

![Dracula Pro Nosferatu on Sublime Text](/images/logs/nosferatu-and-jetbrains-rebuilt-c.webp)

What changed:

- **Full rewrite**: New plugin architecture, CI, and install flow from disk
- **Syntax aligned with VS Code Pro**: Tags pink, attributes green italic, functions green, strings yellow, types and builtins cyan italic, generics orange, CSS selectors pink
- **Every Pro palette**: Pro, Blade, Buffy, Lincoln, Morbius, Nosferatu, Van Helsing, and Alucard — each with an Islands counterpart
- **Matched chrome**: Selected rows, tabs, buttons, checkboxes, hover states, and focus rings stay readable on every palette
- **Automatic editor scheme**: Switching a Dracula Pro UI theme also switches the matching editor color scheme
- **Requires JetBrains IDE 2025.3 or later**

Reinstall from the zip in your [Gumroad library](https://app.gumroad.com/library): **Settings → Plugins → Install Plugin from Disk…**, then pick a Dracula Pro palette under **Appearance**.
